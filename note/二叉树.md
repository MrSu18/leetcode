# 遍历
- 中序遍历、先序遍历、后序遍历的区别就是在于根节点的位置在哪，左右时不变的
    ```
    先序遍历：root、left、right
    中序遍历: left、root、rigt
    后序遍历: left、right、root
    ```
## 94.中序遍历
- 递归版本
    ```c++
    class Solution 
    {
    public:
        vector<int> inorderTraversal(TreeNode* root) 
        {
            vector<int> result;
            traveltree(root,result);
            return result;
        }
    private:
        void traveltree(TreeNode* root, vector<int> &result)
        {
            if (root==nullptr)
            {
                return;
            }
            
            traveltree(root->left,result);
            result.push_back(root->val);
            traveltree(root->right,result);
        }
    };
    ```
    **重点：** `traveltree` 函数的递归终止条件是 `root == nullptr`，即访问到某个节点的空孩子时直接返回，而不是在叶子节点处结束。

    中序遍历的执行顺序如下：
    1. 递归遍历左子树；
    2. 将当前根节点的值加入 `result`；
    3. 递归遍历右子树。

    因此，节点会按照“左子树 → 根节点 → 右子树”的顺序被记录。如果要改写为前序遍历或后序遍历，只需要调整上述三条语句中“访问根节点”这一步的位置即可。
